# Developer utility kit v0.1

`villagelink.utility` is a Python, in-memory view of publications explicitly
supplied by the caller. It does not crawl, fetch, federate, rank, or decide
whether any equality assertion is true. It uses the existing `vl:` codec.

```python
from villagelink.codec import make
from villagelink.utility import Graph, Publication, inspect, validate

a, b, c = "urn:example:a", "urn:example:b", "urn:example:c"
records = [
    Publication(make(a, b), "https://publisher.example/ab", evidence_uri="https://publisher.example/evidence"),
    Publication(make(b, c), "https://other.example/bc", observed_at="2026-09-28T00:00:00Z"),
]
graph = Graph(records)
assert validate(records[0].link)
assert inspect(records[0].link).left == a
assert graph.connected(a, c, max_depth=2)
for path in graph.paths(a, c, max_depth=2):
    for step in path:
        print(step.source, step.target, step.publications)
```

`parse(uri)` returns `(left, right)` in encoded order; `inspect(uri)` returns a
`Link(uri, left, right)`. Both raise `ValueError` for bad syntax. `validate(uri)`
returns a boolean and checks only the `vl:` encoding and absolute endpoint URI
syntax. No endpoint is dereferenced.

`Publication(link, source_uri, observed_at=None, evidence_uri=None)` records
one occurrence of a published assertion. `source_uri` identifies its publication
location. `observed_at` is an optional caller-supplied string, not a time
generated by the kit. Multiple records of the same relation remain distinct.

`Graph(publications)` snapshots those records. `adjacent(uri)` returns direct
`Step(source, target, publications)` records; the publication tuple preserves
all supplied occurrences, including reversed encodings of the same symmetric
relation. `traverse(uri, max_depth)` returns breadth-first discovery steps.
`component(uri, max_depth)` returns reachable trace URIs, including the start.
`connected(left, right, max_depth)` checks for a structural path; `paths` returns
all simple paths within the bound. A zero-hop path connects a URI to itself.
All depth arguments are required non-negative integers. Listing every simple
path can be expensive on a dense local graph, so callers should choose a small
bound and dataset. Traversal never repeats a trace in a path.

**Connectivity is not established equivalence.** A false or disputed assertion
remains traversable and its publication remains inspectable. Contradiction,
corroboration, trust, evidence assessment, indexing and remote discovery are
outside this version.
