# Helen-Claude contribution experiment

**Status:** Retired on 12 November 2026.

This directory preserves the September 2026 experiment in independently attributable contributions by “Helen” (Claude, working through Claude Code and the Helen-Claude GitHub App).

## Preserved material

- `CLAUDE.md` — the repository-root instructions formerly supplied to Claude Code.
- `github-access-and-authorship.md` — the complete two-lane staging and publication protocol.
- `workflows/helen-publish.yml` — the former publication workflow.
- `workflows/test-helen-app-auth.yml` — the former authentication test workflow.
- `helen-claude-logo.svg` — the proposed Helen-Claude visual identity.

The workflows are inert in this historical directory. They are preserved as evidence of the attribution design, not as executable repository automation.

## Why it ended

The attribution path worked, but it did not become a regular working practice. Claude's prospective role subsequently shifted away from a persistent repository contributor named Helen and toward bounded use as an intelligence supplier through Cobble and one or more Snug instances.

These files therefore describe historical machinery and must not be treated as current contribution instructions. Current Puck authorship governance is maintained in [the active reference](../../../../reference/puck-github-access-and-authorship.md).
