# Contributing to Village Link

Village Link is an early-stage experimental project intended to develop as open public infrastructure.

The project welcomes criticism, questions and contributions. You do not need to accept the current architecture to participate. If the core statement — **W states A ↔ B** — is useful, one of the most valuable contributions is to show where it breaks.

## Ways to contribute

Useful contributions include:

- edge cases and counterexamples;
- alternative architectures;
- privacy, safety and abuse analysis;
- comparisons with existing standards and systems;
- improvements to the specification, requirements and terminology;
- prototype code, tests and documentation; and
- small, clearly sourced demonstration datasets.

A question or well-described objection is a contribution. Code is not the only way to help.

## Before doing substantial work

For a small correction or contained improvement, feel free to open a pull request directly.

For a substantial change, please open an issue first. This lets contributors compare approaches before anyone invests heavily in an implementation that may not fit the project's current direction.

Architectural decisions should be inspectable. Material changes may require an Architecture Decision Record (ADR) before or alongside implementation.

## Pull requests

1. Fork the repository or create a branch from `main`.
2. Keep the change focused and explain what problem it addresses.
3. Update relevant documentation and tests.
4. Run the applicable tests described in the relevant project-area README.
5. Open a pull request and identify any unresolved questions or trade-offs.

Review is a conversation. Maintainers may ask for changes, propose a different approach or decide not to merge a contribution. When a decision is architecturally significant, the reasoning should be recorded in the repository.

## Current stewardship

Village Link was initiated by Joe Rasmussen and is currently developed and stewarded through Inky Tech Pty Ltd.

During this early stage, the repository maintainers decide what is merged and how releases are made. The intended direction is neutral, openly governed infrastructure. Stewardship arrangements may therefore evolve as the project and contributor community develop.

Contributing to Village Link does not require joining Inky Tech. A contribution does not by itself create employment, partnership, equity or authority to represent Inky Tech or the project.

Maintainers, contributors and advisers may participate at different levels and may change roles over time. These are project responsibilities, not measures of personal standing.

## Working together

Be generous with people and rigorous with ideas.

- Criticise claims and designs, not contributors.
- State uncertainty and distinguish evidence from inference.
- Credit prior work and disclose relevant interests.
- Treat privacy, safety and misuse concerns as design inputs rather than obstacles to be dismissed.

Village Link is young. Clear disagreement, recorded openly, is part of how it will improve.
